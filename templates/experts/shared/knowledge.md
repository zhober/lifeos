# Shared external reference pointers

Store a cross-domain reference once with title, URL, evidence level, lookup date, population/applicability, uncertainty, and relevant domains. Other expert knowledge files link the same entry. Distinguish versions and retain earlier references when guidance changes.

## References

Medical references follow docs/domains/HEALTH.md and templates/health-source.json. Keep authority, claim certainty, applicability, provenance/channel, reading scope, version status and limitations explicit. Trace reposts and expert summaries to the same original evidence; original-source duplication does not establish corroboration. Preserve published ratings separately from provisional model appraisal.

This directory does not contain a second personal memory store. Reference agreement does not establish independent personal evidence.
