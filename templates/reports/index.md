# Daily reports

Use docs/domains/REPORTING.md. JSON/Markdown/HTML and optional PDF are immutable derived versions under daily/YYYY/YYYY-MM-DD/report-<id>/. Sources and current disclosure govern reuse; the report is not another authoritative personal profile.

Default style is data/actions. Automatic generation follows a real morning sleep submission and completed source-bound analysis, including next-day waking-date attribution. No fixed clock schedule, background monitor or personal report is initialized by this template.
